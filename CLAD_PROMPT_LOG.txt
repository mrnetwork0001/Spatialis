[PROMPT 5] Shared core module
Agent Action: Generated Scripts/SpatialisCore.ts — the vocabulary the four
  subsystems agree on, so none of them holds a direct reference to another:
   - SurfaceKind / PlacementHint / IntentAction / SpatialisIntent types.
   - FURNITURE_CATALOG: 12 entries, each with a real-world footprint (cm),
     height, default placement and spoken aliases.
   - resolveFurniture(): longest-alias match, so "coffee table" beats "table".
   - SpatialisRegistry: process-wide registry of everything placed in the room
     (Voice adds, Gesture mutates, Anchor re-seats, Material restyles).
   - Math helpers: framerate-independent damp(), easeOutBack/Cubic,
     yawTowards(), alignToNormal(); plus a small Tween/TweenPool.
Result: 509 lines. Each subsystem drives its own TweenPool from its own
  UpdateEvent, so there is no hidden update-order coupling between them.

[PROMPT 6] Subsystem 3 — Surface Anchor Engine
Agent Prompt: "Detect physical floors, tables and walls and snap 3D objects
  cleanly to real surfaces."
Agent Action: Generated Scripts/SurfaceAnchorEngine.ts.
  - World Query hit-test session (filtered) with a request QUEUE: the API
    permits one hit test in flight and answers on a later frame, so probes are
    queued and drained in onUpdate rather than issued ad hoc.
  - classify(): floor / table / wall / ceiling from the surface normal PLUS
    height above a running floor estimate — a table is "horizontal, but 30 to
    130cm up", which is the only way to tell a tabletop from the floor.
  - Floor height calibrated by a downward probe at start, eased (not hard-min)
    so one bad depth sample cannot drop the floor through the ground; falls
    back to eye height minus 155cm when depth is not yet available.
  - Retry pass: if the gaze ray hits the wrong surface kind for the piece
    (art wants a wall, a sofa wants a floor), re-probe rather than mis-anchor.
  - resolveOverlap(): golden-angle spiral search outward on the surface plane
    so a new piece does not spawn inside an existing one.
  - reseat(): drops a ray from above a released object to settle it, keeping
    the user's chosen X/Z and correcting only height.
Result: 649 lines.

[PROMPT 7] Subsystem 1 — Voice Intent Engine
Agent Prompt: "Listen to voice commands and spawn 3D prefabs with scale-in
  animations."
Agent Action: Generated Scripts/VoiceCommandController.ts.
  - VoiceML listening with interim + final transcription; interim text is
    displayed but never acted on; duplicate final transcripts are debounced.
  - Slot-filling parser rather than a grammar: scans the whole utterance for
    verb / noun / finish / colour / placement, so disfluent real speech
    ("uh put a like dark wood coffee table over there") still resolves.
  - Actions: spawn, material, color, scale, delete, clear.
  - Spawn animation: easeOutBack scale-in plus a short drop, so a piece settles
    onto its surface rather than blinking into existence.
  - Optional wake word; optional on-screen feedback Text.
Result: 673 lines.

[PROMPT 8] "by the wall" is not "on the wall"
Agent Finding: The spec's headline command is "Spawn a Scandinavian lounge
  chair BY the wall". Treating that as a wall placement would hang a chair on
  the wall. "by / against / near the wall" is a FLOOR placement backed up to a
  wall — a different operation.
Agent Action: Extended requestPlacement() with a wallAdjacent path using two
  chained probes: a level ray finds the wall and its normal, then a downward
  ray stepped off the wall by the piece's own footprint finds the floor there.
  The piece is turned to face the room. Falls back to plain floor placement
  when no wall is in view.
Result: Headline command now behaves as spoken. Verified by test.

[PROMPT 9] Subsystem 4 — PBR Material Swapper
Agent Prompt: "Dynamically update wood, fabric and metal textures on spatial
  objects."
Agent Action: Generated Scripts/PBRMaterialSwapper.ts.
  - 11 finishes (oak, walnut, velvet, linen, leather, marble, concrete, brass,
    chrome, matte black, smoked glass) with plausible metallic/roughness, and
    10 named tints applied independently of the finish.
  - CORRECTNESS: Lens Studio Materials are shared assets. Writing to
    mainMaterial directly would restyle every sofa in the room at once, so each
    object receives a one-time private clone on first restyle.
  - ROBUSTNESS: every shader uniform write is individually guarded, so a prefab
    on a custom shader degrades to colour-only instead of throwing mid-frame.
  - Cross-fades colour, metallic and roughness over ~0.45s.
Result: 505 lines.

[PROMPT 10] Subsystem 2 — Hand Gesture Controller
Agent Prompt: "Implement SPECS hand tracking for pinch, drag, rotate and scale
  operations in 3D space."
Agent Action: Generated Scripts/SpatialGestureController.ts.
  - Pinch derived from thumb/index joint distance with HYSTERESIS (close at
    3.0cm, open at 4.5cm). At arm's length the tracked joints jitter by
    millimetres and a single threshold makes furniture flicker between grabbed
    and dropped; a separate release distance removes that class of bug.
  - One hand pinched  -> grab and drag, offset preserved so nothing snaps.
  - Two hands pinched -> scale by hand separation (clamped 0.3x-3.0x of the
    piece's own size) and rotate by the yaw swept between the hands.
  - Collapsing two hands back to one continues the drag instead of releasing.
  - Losing hand tracking mid-grab is treated as a release, so a piece settles
    onto a surface instead of freezing in mid-air.
  - Release hands off to SurfaceAnchorEngine.reseat(); a re-grab during the
    in-flight hit test is detected so the piece is not yanked back.
Result: 564 lines.

  engine's no-camera fallback, which could throw on an empty scene.
  SECOND RUN: clean.

[PROMPT 12] Closing the loop — behavioural tests on the parser
Agent Rationale: The parser is the one subsystem that cannot be validated by
  looking through a headset — it either understands a sentence or it does not.
Agent Action: Generated Tests/lens-runtime-stub.js (Node stand-in for the Lens
  Studio globals) and Tests/voice-parser.test.js (26 cases: the demo script,
  plus the phrasings most likely to be spoken instead).
Result: FIRST RUN FAILED — two genuine parser defects found:
  (a) "make the chairs navy" did not resolve, because catalog aliases were
      singular and speech is often plural.
      FIX: resolveFurniture() now also matches the naive plural.
  (b) "make it twice as big" did not resolve, because the size vocabulary
      lacked the bare adjective "big". Naively adding it broke "add a big
      sofa", which then parsed as a resize instead of a spawn.
      FIX: action precedence reordered so an explicit spawn verb plus a noun
      always wins, and a size word only means "resize" when it is not merely
      describing a piece being spawned.
  SECOND RUN: 26 passed, 0 failed — including both spec headline commands.
